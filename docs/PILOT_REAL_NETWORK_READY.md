# Пилот ClubPay в реальной компьютерной сети

Это готовая инструкция для запуска одного реального тестового ПК в клубе.

Пилот **уже создан в production**. Коллеге не нужно создавать сеть, клуб, зону, тарифы или компьютер вручную. Не используем Demo, Test Cyber Club и VM: у пилота отдельные данные, QR-код, сессии и ваучеры.

## 2. Что подготовить до выезда

- Raspberry Pi с питанием, SD-картой/SSD, Ethernet и постоянным IP в сети клуба.
- Один тестовый игровой ПК, подключённый к сети **по Ethernet**.
- Фактический MAC-адрес проводной сетевой карты тестового ПК.
- Доступ администратора к BIOS и Windows этого ПК.
- Телефон с Telegram и подключением к гостевому Wi-Fi клуба.
- Доступ владельца к веб-админке ClubPay: `https://clubpay.justix.uz/admin`.
- Core token для пилота: его передают отдельно в защищённом канале. В Git, скриншоты и общий чат его не отправлять.
- Для онлайн-оплаты — тестовые ключи Payme/Click. Если ключей пока нет, весь основной сценарий можно проверить наличными, ваучером и mock-оплатой без реальных списаний.

## 3. Настройка игрового ПК

### 3.1 BIOS и Windows

1. В BIOS включить Wake-on-LAN / Power on by PCI-E.
2. В Windows в свойствах сетевой карты включить возможность пробуждать ПК и разрешить magic packet.
3. Отключить Windows Fast Startup, иначе WoL после выключения может не сработать.
4. Установить Steam и нужные игры **на сам игровой ПК**. ClubPay игры не скачивает и не хранит: Agent находит локально установленные Steam-игры и запускает их.

### 3.2 Установка Agent Core

На ПК установить Git и .NET SDK 10, затем открыть командную строку от имени обычного пользователя и выполнить:

```bat
git clone https://github.com/llcjustix/clubpay-core-agent.git C:\ClubPay\source
cd /d C:\ClubPay\source
dotnet publish .\src\ClubPay.Agent.Client\ClubPay.Agent.Client.csproj -c Release -r win-x64 --self-contained true -o C:\ClubPay\Agent
```

В `C:\ClubPay\Agent\appsettings.Local.json` создать локальный конфиг:

```json
{
  "Agent": {
    "PcId": "Pilot PC #01",
    "ClubName": "Pilot — Real Network",
    "Zone": "Pilot Standard",
    "VoiceAnnouncementsEnabled": true,
    "KioskLockdownEnabled": false,
    "HideWindowsTaskbar": false,
    "MaintenanceExitEnabled": true
  },
  "Controller": {
    "WebSocketUrl": "wss://api-clubpay.justix.uz/api/core/ws",
    "BootstrapUrl": "https://api-clubpay.justix.uz/api/core/bootstrap",
    "AgentToken": "<CORE_TOKEN_ПИЛОТА>",
    "ExternalPcId": "pilot-real-network-pc-001"
  },
  "Launcher": {
    "DiscoverSteamGames": true,
    "SteamLibraryRoots": [],
    "Apps": []
  }
}
```

Запуск для первого теста:

```bat
start "" C:\ClubPay\Agent\ClubPay.Agent.Client.exe
```

Сначала проверяем всё в режиме обслуживания: `KioskLockdownEnabled: false`, `HideWindowsTaskbar: false`, `MaintenanceExitEnabled: true`. После успешной проверки и только для игрового ПК включаем kiosk-режим: `KioskLockdownEnabled: true`, `HideWindowsTaskbar: true`, `MaintenanceExitEnabled: false`.

В админке открыть `Настройки → Компьютеры → Pilot PC #01 → Изменить` и указать реальный MAC-адрес сетевой карты ПК. Без MAC и настройки BIOS/Windows Wake-on-LAN работать не будет.

## 4. Raspberry Pi / локальный Controller

Raspberry Pi должен быть в той же локальной сети, что и тестовый ПК. Облачный API не может отправить magic packet в сеть клуба — это делает только Pi/Controller.

На Pi задать постоянный IP и настроить Controller со следующими параметрами:

```env
NODE_MODE=edge
CORE_MODE=ws
CORE_TOKEN=<CORE_TOKEN_ПИЛОТА>
EDGE_CLUB_ID=564ef225-6cdb-4bf9-a362-960f942b3c4d
WOL_ENABLED=true
WOL_BROADCAST_ADDR=255.255.255.255:9
WOL_WAIT_SECONDS=60
```

Controller должен иметь исходящий доступ по HTTPS/WSS `443` к `api-clubpay.justix.uz`. У Pi не нужен входящий публичный порт. После запуска Controller и Agent должны подключиться к Core; в админке ПК перестаёт быть `offline`.

## 5. Как проверить пилот по шагам

### Базовый запуск

1. Открыть постоянный QR с телефона. Должна открыться страница оплаты именно `Pilot PC #01` в клубе `Pilot — Real Network`.
2. В веб-админке запустить наличную сессию на `Pilot PC #01`.
3. На экране ПК Agent должен получить `start_session`, перейти в активную сессию, показать таймер и временный QR продления.
4. В Agent открыть Steam, затем установленную игру. Windows Explorer, обычный taskbar и посторонние окна не должны стать доступны игроку в kiosk-режиме.

### Продление и Frozen

1. Во время активной сессии отсканировать QR продления, оплатить тестовым способом или применить ваучер.
2. Проверить, что добавляется время **к той же сессии**, а не создаётся новая.
3. Дождаться окончания времени. ПК должен перейти в `FROZEN` на 3 минуты.
4. В `FROZEN` отсканировать QR продления и продлить сессию: оплата должна быть доступна, а ПК вернуться в активную сессию.

### Ваучер и Telegram

1. Завершить сессию досрочно через меню Agent или из веб-админки.
2. Указать номер телефона и подтвердить согласие на получение ваучера.
3. Если номер ещё не связан с ботом, открыть `@clubPay_tg_bot`, нажать Start и привязать номер.
4. Проверить автоматическую доставку ваучера на остаток времени и затем его применение на QR-странице ПК.

### Перезапуск и голос

1. Перезапустить Agent во время активной сессии. После переподключения он должен восстановить состояние, таймер и QR продления.
2. Проверить голосовые уведомления за 30, 10 и 5 минут. На коротком тесте сессии можно проверить событие 5 минут.

### Wake-on-LAN

1. Убедиться, что ПК в админке имеет статус `sleeping`, а не `offline`.
2. Перевести ПК в сон, не выключая Raspberry Pi/Controller.
3. Оплатить постоянный QR.
4. Controller отправляет WoL magic packet, ПК загружается, Agent переподключается и сессия стартует.
5. Если Agent не вернулся за 60 секунд, ожидаемая ошибка — `wol_failed`; повторно списывать оплату нельзя.

### Гостевой Wi-Fi

1. Подключиться к отдельному SSID гостей.
2. Устройство должно получить redirect на QR-страницу ClubPay/Captive Portal.
3. До авторизации гостевая сеть не должна давать доступ к игровым ПК, управляющей сети, роутерам и внутренним сервисам.
4. Должны быть разрешены только DNS, DHCP и HTTPS к ClubPay/платёжным доменам.

## 6. Когда считаем MVP готовым

Пилот считается успешно пройденным, если на реальном ПК подтверждены все пункты:

- Agent и Controller стабильно online;
- постоянный QR открывает правильный ПК;
- наличная/тестовая оплата запускает сессию;
- локально установленный Steam и игра запускаются из Agent;
- продление работает в активной сессии и `FROZEN`;
- ваучер на остаток создаётся и приходит через Telegram;
- после перезапуска Agent восстанавливает текущую сессию;
- Wake-on-LAN будит спящий ПК и запускает сессию;
- гостевая сеть изолирована от сети клуба.

Реальные Payme/Click-списания и финальная настройка Captive Portal проверяются отдельно после выдачи ключей провайдеров и доступа к сетевому оборудованию клуба.

## 7. Что коллеге делать не нужно

- Не создавать вручную новую сеть, клуб, зону, тарифы или ПК.
- Не переиспользовать QR из Demo/Test Cyber Club или VM.
- Не менять production БД напрямую.
- Не хранить Core token, пароли или Telegram token в конфиге Git, скриншотах и общем чате.

Его задача: установить Agent на тестовый ПК, настроить Pi/Controller, указать MAC в существующем `Pilot PC #01`, проверить сценарии раздела 5 и прислать результат каждого шага.
