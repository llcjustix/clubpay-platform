# Первый вход: ручная проверка

## Вход через Telegram

Запускайте приложение с production API:

```sh
cd mobile/clubpay_client
flutter run -d chrome --web-port=7357 --web-hostname=localhost \
  --dart-define=API_BASE_URL=https://api-clubpay.justix.uz
```

Сценарий: **номер → Продолжить → Открыть Telegram → Start → отправить свой
контакт кнопкой бота → получить OTP → вернуться в приложение → ввести OTP →
главная**. После номера приложение не показывает и не получает тестовый код.
Код создаётся и отправляется ботом только после того, как пользователь поделился
своим контактом; номер контакта должен совпадать с введённым.

Код действует 3 минуты и работает один раз. После 5 неверных попыток нужен
новый запрос. **Получить новый код** возвращает к вводу номера; лимиты: до 3
запросов на номер и 5 на устройство за 15 минут.

Проверьте также, что после перезагрузки вход сохранён, а после выхода профиль
не открывается без новой авторизации.
